Задача створити архів з файлами що були зміненні.  
Для введення проекту
використовувався git тому всі зміни запротокольовані.

git log --oneline

```
7za a -tzip changed_files.zip @filelist.txt
```

Тепер файл містить змінені файли changed\_files.zip

Якщо не треба копіювати видалені файли тоді список змінених файлів можна отримати
так:

```
git diff --name-status 633d17514 4580129c9 | egrep -v "^D\t" | awk '{print $2}' > filelist.txt
```
