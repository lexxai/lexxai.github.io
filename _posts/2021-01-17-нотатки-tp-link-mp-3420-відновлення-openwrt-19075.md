*TP-LINK MP 3420v2 extUSB*

[[OpenWrt Wiki] TP-Link TL-MR3420 & TL-MR3220](https://openwrt.org/toh/tp-link/tl-mr3420)

Нотую для себе, деякі послідовності.  
Так як за своєї помилки прибив роутер, то мені і відновлювати.  
Так як мені потрібен функціонал якого не має в рідній прошивці, такі як VLAN, MultiAP ... То компілюю OpenWrt для цього роутера з останньою версією. Але флеш пам'ять цього пристрою всього 4МБ і 32МБ оперативної пам'яті, тому використовую зовнішній USB диск, як розширений простір (ext\_root). А у подальшому можливо буде заміна флеш на 8МБ.

#### Flash via tftp

Using a serial line.

[![](/assets/images/blog/e963407701a57bcd-b8a7534928301aff.jpg)](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEjvQYptckTXFBBVuyVaBwFxwDDVGtDpLrKd0fvDx6q4popFrbREbkV11_T1AbG7qa2Mi9HrGbCAchgCAmuDIdlXihqk2jWGUgyzYrPZRrAb-_pEDVVNpXT-yN2xn25Ti6PMU5VnZvJLSJ8m/s3486/IMG_20210115_221420.jpg)

  

[![](/assets/images/blog/c8cafd82eb9a3c73-77fb1ca4e07325c1.jpg)](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEiF5rHNnoVIoXk9u28rA-di2QRzq5QeR77-uAGF22MhekEJ0P-kyR5vffFIZAIvsXaOtFLCuUQbFyTROqt7yTNJcMtjdN_FV5Yf5aruRaIpGM1OHm5d8S1IkEF8kceNVcLnTirVKau3eEFH/s3158/IMG_20210115_221440.jpg)

Download the factory update firmware: openwrt-ar71xx-generic-tl-mr3420-v1-squashfs-factory.bin  
Connect your pc via serial interface.  
Set up tftp server with IP 192.168.1.100 (for MR3420/MR3220 versions v2.x).  
Rename the firmware to code.bin and move to tftp folder.

Power on the router, and type **tpl** if “Autoboot in ..” occurs (type fast!)  
If it works you now should see something similar: wasp>

[![](/assets/images/blog/96b0a8050568f763-787fcc753cd7823f.png)](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEhptGA-WFQzUh5hDoPmg2NqRZe91qnFPImUJ7rs1BRV3TxGfYvQEKvH80meMkTpXy-TYfe60-8sRjg43UQ4sSfH4n_p0DyGqVe9TSQWons4HeE61Vsml4zuq0RL8jwnXLfh8L2e_4SK14t7/s1088/%25D0%2597%25D0%25BD%25D1%2596%25D0%25BC%25D0%25BE%25D0%25BA+%25D0%25B5%25D0%25BA%25D1%2580%25D0%25B0%25D0%25BD%25D1%2583+%25D0%25B7+2021-01-16+23-42-14.png)  
*Як з Arduino IDE монітор послі. порту відіслати швидко: tpl*

  

Now you should type the following:

```
wasp> erase 0x9f020000 +0x3c0000  
wasp> tftpboot 0x81000000 code.bin  
wasp> cp.b 0x81000000 0x9f020000 0x3c0000  
wasp> bootm 0x9f020000
```

#### Резервування ART

by ssh

```
cat /proc/mtd  
dev:    size   erasesize  name  
mtd0: 00020000 00010000 "u-boot"  
mtd1: 00130948 00010000 "kernel"  
mtd2: 0029f6b8 00010000 "rootfs"  
mtd3: 00090000 00010000 "rootfs_data"  
mtd4: 00010000 00010000 "art"  
mtd5: 003d0000 00010000 "firmware"

cat /dev/mtd4 > /tmp/mtd4.bin  
cat /dev/mtd0 > /tmp/mtd0.bin  
cat /proc/mtd > /tmp/mtd.txt

scp root@192.168.1.1:/tmp/mtd4.bin mtd4.bin  
scp root@192.168.1.1:/tmp/mtd0.bin mtd0.bin  
scp root@192.168.1.1:/tmp/mtd.txt mtd.txt
```

#### Компіляція OpenWrt під себе

Потрібна тільки підтримка USB носія в мінімуму.  
block-mount, mod-scsi-core,kmod-usb-storage,kmod-fs-ext4  
Вимикаю IPv6, PPP.  
  
Для роботи файлу "підкачки":  
Global build settings -> Kernel build options -> [\*] Support for paging of anonymous memory (swap)
  
  
config.buildinfo:

```
CONFIG_TARGET_ar71xx=y  
CONFIG_TARGET_ar71xx_tiny=y  
CONFIG_TARGET_ar71xx_tiny_DEVICE_tl-mr3420-v2=y
```
