### Керування

Для керування через WiFi, використовується відома програма "[Magic Home Pro](https://play.google.com/store/apps/details?id=com.zengge.wifi&hl=uk)".

Пристрій запам'ятовує останнє налаштування, і використовує їх при подачі
напруги.

Також пристрій може працювати у хмарі, разом з "Google Ok" розуміє команди
ввімкнено/вимкнено, встановлення рівня яскравості, так кольору.

Також пристрій може працювати без хмари, тільки у локальній мережі.

### Локальна мережа

Для роботи у локальній мережі використовуватися як програма "[Magic Home Pro](https://play.google.com/store/apps/details?id=com.zengge.wifi&hl=uk)", так і альтернативні програми.

Рішення які використовують відмий протокол (zengge) керування через порт TCP:
5577

* [namacha / python-magichue](https://github.com/lexxai/python-magichue)
  ([перевірено мною і додано зміни](https://github.com/lexxai/python-magichue))

Приклад застосування для керування:

```
#! /bin/env python3  
  
import time  
import magichue  
  
light = magichue.Light('192.168.0.164')   
print(light)  
print(light._get_status_data())  
  
light.is_white = True  
light.cww = (2,112)  
time.sleep(3)  
light.on = False
```
