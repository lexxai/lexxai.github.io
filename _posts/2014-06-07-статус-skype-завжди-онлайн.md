Ваш статус "Skype" завжди онлайн , навіть коли Ви закрили програму?  
Цікаво що це проблема дуже популярна, але розробник не надає ні яких рекомендацій.  
Але спільнота, дещо знайшла.  
  
Є команди що виконуються у любому з вікон чату. Наприклад: /help.  

[![](/assets/images/blog/58afce04295ecb64-667b0a9bceed9020.png)](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEjblwe-7razUAgwUXU9p-ymDLyOkRL5DRZiiGRhd8oVISefu0JGmy_bgjvgN_kBFp5YzWMVV0ebi7X80E3g_j1oR1s2-42Fu1VAnyBRQ207xED2VRu7gQ687eyp_fA_m1IBzygwDsxxMrCI/s1600/skype-command-01.png)  
*Skype команди*

Повний перелік команд можна знайти тут: <http://www.skype.com/go/help.chathelp>  
А для домомоги з статусом "Skype" який завжди онлайн, допоможуть ось ці:  
 /showplaces — показує з яких гаджетів Ви залогінені  
/remotelogout — Вийти з усіх гаджетів, крім поточного. При цьому буде зупинено отримання push-повідомлень у всіх інших гаджетах.  
І так вводимо  /remotelogout в чаті та натискаємо клавішу ентер.  
Все. Повинно викинути ваші всі реєстрації, навіть невдалі, з усіх гаджетів, крім поточного.  
У моєму випадку допомогло.  
  
P.S. [Які команди й ролі доступні в Skype для чату в хмарі?](https://support.skype.com/uk/faq/FA10042/yaki-komandi-y-roli-dostupni-v-skype-dlya-chatu-v-khmari)  
Команда   

|  | Опис |
| --- | --- |
| /add [ім’я в Skype] | За допомогою цієї команди можна додати учасника до розмови. Наприклад, після введення команди **/add anetta0806** цього користувача буде додано до чату.   Деякі імена в Skype починаються з "live:" (наприклад, **live:anetta0806**) |
| /alertson [текст] | Ця команда дає змогу налаштувати необхідні оповіщення. Наприклад, за допомогою команди **/alertson Лондон** ви будете отримувати оповіщення щоразу, коли слово "Лондон" з’являтиметься в чаті. |
| /alertsoff | За допомогою цієї команди можна вимкнути оповіщення. |
| /find [текст] | Ця команда дає змогу шукати певні слово або фрагмент тексту в чаті. Наприклад, команда **/find Ольга** поверне фрагмент тексту в чаті, коли це слово зустрілося вперше. |
| /get admins | За допомогою цієї команди можна переглянути відомості про адміністраторів чату. |
| /get options | Ця команда дає змогу переглянути та налаштувати параметри поточного чату. |
| /get role | Ця команда дає змогу дізнатися, яку роль у чаті вам призначено. |
| /showmembers | За допомогою цієї команди можна переглянути список учасників і їхні ролі. |
| /get uri | Ця команда використовується для створення URL-адреси, за допомогою якої інші користувачі можуть приєднатися до групового чату. |
| /golive | Ця команда дає змогу розпочати конференцію з учасниками чату. |
| /info | За допомогою цієї команди можна переглянути фактичну та максимально можливу кількість людей у чаті. |
| /kick [ім’я в Skype] | За допомогою цієї команди можна видалити користувача з чату. Наприклад, після введення команди **/kick anetta0806** цього користувача буде видалено з чату. |
| /leave | Ця команда використовується для виходу з поточного групового чату. |
| /me [текст] | Ця команда дає змогу розмістити поруч із вашим іменем будь-який текст. Наприклад, після введення команди **/me працює вдома** текст "працює вдома" з’явиться поряд із вашим іменем у чаті. За допомогою цієї команди ви можете розповісти про свої справи та настрій. |
| /remotelogout | Команда припиняє надходження push-сповіщень в усі екземпляри Skype, крім поточного. |
| /set options [[+|-]параметр] | Ця команда дає змогу налаштувати чат. Наприклад: За допомогою команди **/set options -JOINING\_ENABLED** можна вимкнути параметр JOINING\_ENABLED, а команда **/set options +HISTORY\_DISCLOSED** використовується для ввімкнення параметра HIS. |
|  | Ось список доступних параметрів: |
|  | HISTORY\_DISCLOSED – нові учасники можуть переглядати розмови, що відбулися до того, як вони приєдналися до чату. Тут діють певні обмеження: переглянути можна до 400 останніх повідомлень або історію за два останні тижні. |
|  | JOINING\_ENABLED – нові користувачі можуть приєднуватися до чату. |
| /setrole [ім’я в Skype] SPEAKER | ADMIN | Ця команда дає змогу призначити роль кожному учаснику чату. У таблиці нижче надано опис ролей. |
| /showplaces | Переглянути список усіх кінцевих точок, які можуть отримувати push-сповіщення про дзвінки та миттєві повідомлення на цей обліковий запис Skype. |
| /topic [тема] | За допомогою цієї команди можна змінити тему чату. |
| /get allowlist | Ця команда дає змогу отримати відомості про людей, що мають доступ до цього чату. |
| /get banlist | Ця команда дає змогу отримати відомості про людей, для яких заблоковано доступ до цього чату. |
| /set allowlist [[+|-]маска] .. | За допомогою цієї команди ви можете налаштувати список учасників, яким дозволено брати участь у розмові. Наприклад, після введення команди **/set allowlist +anetta0806** цей учасник зможе приєднатися до розмови. |
| /set banlist [[+|-]маска] .. | За допомогою цієї команди ви можете налаштувати список учасників, яким заборонено брати участь у чаті. Наприклад, після введення команди **/set banlist +anetta0806** цьому учаснику буде заблоковано доступ до чату, а команда **/set banlist -anetta0806** дасть йому змогу знову приєднатися до нього. |
