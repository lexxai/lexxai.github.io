Якщо потрібно тільки показати кирилицю то ось таке рішення :  
<http://www.dosbox.com/wiki/KEYB>  

```
KEYB [keyboard layout code/id]
```

Dosbox.conf:
  

```
[autoexec] 
KEYB none 866
```
