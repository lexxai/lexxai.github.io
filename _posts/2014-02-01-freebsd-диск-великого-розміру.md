FreeBSD 9.1  
Підключав RAID диск з загальним розміром 5Т, але спроба форматувати його стандартними засобами fdisk, label з sysinstall не давали можливість створити розділ з розміром більше а ніж 1.5Т.  
Прочитавши ["Large data storage in FreeBSD](http://www.freebsd.org/projects/bigdisk/)" зрозумів що треба йти іншим шляхом '[gpart](http://www.freebsd.org/cgi/man.cgi?query=gpart&sektion=8)' і '[newfs](http://www.freebsd.org/cgi/man.cgi?query=newfs)'.  
  
Знайшов raid диск /dev/aacd0 (Adaptec AdvancedRAID Controller driver)  
  

```
# ls /dev/aac*
/dev/aac0       /dev/aacd0
```

За публікацією ["Big partitions in FreeBSD > 2TB](https://mebsd.com/configure-freebsd-servers/big-partitions-in-freebsd-bigger-than-2tb.html)" повторюю:  

```
#gpart create -s gpt aacd0
gpart: geom 'aacd0': File exists
```

Рішення цієї проблеми тут: "[Gpart File Exists Error on FreeBSD](http://www.1stbyte.com/2010/08/25/geom-file-exists-error-on-freebsd)"  

```
#gpart destroy  aacd0
aacd0 destroyed
# gpart create -s gpt aacd0
aacd0 created
# gpart add -t freebsd-ufs aacd0
aacd0p1 added
# newfs -U /dev/aacd0p1
```

Монтую,   

```
#mount  /dev/aacd0p1 /mnt/raid
```

Готово.  

```
df -h
Filesystem      Size    Used   Avail Capacity  Mounted on
/dev/aacd0p1    5.4T    8.0k      5T     0%    /mnt/raid
```
